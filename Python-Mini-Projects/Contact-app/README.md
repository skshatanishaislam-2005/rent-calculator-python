# 📒 Contact Book App (Python)

A simple **Contact Book Application** built using Python. This is a beginner-friendly command-line project that allows users to create, manage, search, and delete contacts using a dictionary.

## ✨ Features

- ➕ Create a new contact
- 👀 View contact details
- ✏️ Update an existing contact
- 🗑️ Delete a contact
- 🔍 Search contacts by name
- 📊 Count total contacts
- 🚪 Exit the application

## 🛠️ Technologies Used

- Python 3
- Dictionary
- Loops
- Conditional Statements
- User Input

## ▶️ How to Run

1. Clone this repository:

```bash

```

2. Navigate to the project folder:

```bash
cd contact-book-app
```

3. Run the program:


## 🎯 Learning Objectives

This project helps beginners practice:

- Python dictionaries

- Conditional statements (`if-elif-else`)
- User input handling
- Basic data management

## ⚠️ Current Limitations

This is a basic version of the Contact Book.

- Data is stored only in memory.
- Contacts are lost after closing the program.
- Input validation is limited.
- Contact search is based only on the contact name.
