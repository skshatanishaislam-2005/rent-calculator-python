# 📝 Spell Checker App (Python)

A simple command-line Spell Checker application built with Python. This project uses the **pyspellchecker** library to identify and correct misspelled words entered by the user.

---

## 📌 Features

- ✅ Corrects misspelled words in a sentence.
- ✅ Displays each correction made.
- ✅ User-friendly command-line interface.
- ✅ Runs continuously until the user types **Exit**.
- ✅ Built using Python classes and functions.

---

## 🛠️ Technologies Used

- Python 3
- pyspellchecker Library

## 📦 Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/spell-checker-app.git
```

2. Navigate to the project folder:

```bash
cd spell-checker-app
```

3. Install the required package:

```bash
pip install pyspellchecker
```

---

## ▶️ How to Run

Run the following command:

```bash
python Spell-Check.py
```

## 📖 How It Works

1. The program asks the user to enter a sentence.
2. The sentence is split into individual words.
3. Each word is checked using the `pyspellchecker` library.
4. Incorrect words are corrected automatically.
5. The corrected sentence is displayed.
6. The program continues running until the user enters **Exit**.
